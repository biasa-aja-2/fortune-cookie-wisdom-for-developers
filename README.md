One original fortune-cookie line for a software developer, 72 characters: the bug is never in the code you suspect — it is in the code you trusted. A single balanced sentence that lands in one breath, true about a developer's day, with a quiet twist that rewards a second read: the code you trusted is the blind spot.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (created if missing), pure Python standard library, the same line every run.
